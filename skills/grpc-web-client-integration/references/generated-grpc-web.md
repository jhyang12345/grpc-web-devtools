# Generated grpc-web clients

Use this pattern for clients generated by `protoc-gen-grpc-web` 1.0.4 or newer.
Register every client instance before its first RPC. The immediate check covers
an API that is already installed; the event covers later extension injection.

```ts
import { EchoServiceClient } from "./generated/EchoServiceClientPb";

export const echoClient = new EchoServiceClient("https://api.example.com");
const grpcWebClients = [echoClient];

function installGrpcWebDevtools(): void {
  window.__GRPCWEB_DEVTOOLS__?.(grpcWebClients);
}

installGrpcWebDevtools();
window.addEventListener("grpc-web-dev-tools-ready", installGrpcWebDevtools);
```

Repeated registration is safe. Never freeze a no-op fallback such as this:

```ts
// Wrong: remains a no-op if the extension injects after this assignment.
const enableDevTools = window.__GRPCWEB_DEVTOOLS__ || (() => {});
```

For TypeScript, add the minimum ambient declaration:

```ts
type GrpcWebReplayAdapter = {
  fromJson?: (json: Record<string, unknown>, original: unknown) => unknown;
  createRequest?: (json: Record<string, unknown>, original: unknown) => unknown;
};

type GrpcWebDevtools = ((clients: unknown[]) => void) & {
  registerMethod(method: string, adapter: GrpcWebReplayAdapter): void;
  unregisterMethod(method: string): void;
};

declare global {
  interface Window {
    __GRPCWEB_DEVTOOLS__?: GrpcWebDevtools;
  }
}

export {};
```

## Replay adapters

The extension reconstructs supported scalar, enum, bytes, repeated, and
inferable nested values through generated setters. If a request contains a
field that cannot be inferred safely, register a method adapter in the same
readiness-safe installer:

```ts
function installGrpcWebDevtools(): void {
  const devtools = window.__GRPCWEB_DEVTOOLS__;
  if (!devtools) return;

  devtools([echoClient]);
  devtools.registerMethod("/example.EchoService/Send", {
    createRequest(json) {
      const request = new SendRequest();
      request.setMessage(String(json.message ?? ""));
      request.setLabelsList(
        Array.isArray(json.labels) ? json.labels.map(String) : []
      );
      return request;
    },
  });
}
```

Use the exact method path shown in a captured entry. Prefer generated message
constructors and setters; do not send an untyped plain object to the transport.
